# Продуктивность — привычки и задачи

Личный дашборд Глеба. Статика: HTML + CSS + JS, без сборки и без бэкенда.
Данные лежат в репозитории в JSON и пишутся прямо со страницы через GitHub API.
Каркас, календарь и запись в GitHub взяты из дашборда агентства (`~/Documents/gbm-dashboard`).

## Запуск локально
```bash
cd ~/Documents/life-dashboard
python3 -m http.server 8788    # открыть http://localhost:8788
```
После правки `app.js` / `style.css` — `python3 tools/stamp.py` (версия в ссылках против кэша браузера).

## Листы
- **Динамика** — итог за период и один таймлайн **всегда по дням**, при любом периоде: две линии
  на фоне зон. Привычки — тёмная линия с круглыми точками, задачи — фиолетовая с квадратными;
  точка окрашена в цвет зоны. Наведение/тап по дню показывает «сделано из поставленного» и,
  для привычек, что именно пропущено.
  Галочки в шапке таймлайна: «Привычки», «Задачи», «Линии» (между точками), «Зоны» (цветной фон)
  (без зон — пунктир на 50% и 75%). Выбор запоминается в браузере.
- **Отметить** — день (по умолчанию сегодня, стрелками можно назад), привычки в один тап,
  задачи «поставлено / сделано», кнопка «Сохранить» = коммит. Внизу — управление списком привычек.

## Зоны
красная — меньше 50% · голубая — 50–75% · зелёная — 75% и выше (ровно 75% — зелёная, ровно 50% — голубая).

## Данные

### `data/habits.json`
```json
{ "id": "run", "name": "Бег утром", "active": true }
```
Привычки не удаляются, а отключаются (`active: false`) — иначе в истории пропадут названия.

### `data/days.json` — одна запись на день
```json
{ "date": "2026-10-08", "h": { "wake": false, "run": true, ... }, "done": 5, "planned": 8 }
```
- `h` — все активные на момент отметки привычки: `true` сделал, `false` нет.
  Привычки ежедневные: прошедший день без `h` (с первого дня учёта привычек) считается как **0 из N**,
  N — размер списка на тот день. Сегодня без отметки не считается, пока день не закончился.
  Знаменатель дня = число ключей, поэтому смена списка привычек не пересчитывает прошлое.
- `k` — три ключевые задачи дня (на развитие, не операционка), только отметки: `[{"d": true}, {"d": false}, {"d": false}]`.
  Сами задачи Глеб ведёт в другом месте.
  Считаются как сделанные из 3; прошедший день без `k` (с первого дня учёта) = 0 из 3.
  График «Ключевые задачи» на листе «Статистика» — столбики 0–3, цвет по зонам (1 — красный, 2 — голубой, 3 — зелёный).
- `done` / `planned` — задачи. `planned: 0` = день не распланирован и считается как **0 из 1**
  (распланировать день — тоже задача): 0% на графике и +1 к поставленным в итоге периода.
  Разрыв линии — только там, где записи за день нет вообще.

## Как считается
- **Процент за период** — сумма сделанного ÷ сумма поставленного, а не среднее дневных процентов.
  День без плана добавляет 0 из 1.
- Дни из таблицы с «0 из 1» перенесены как `planned: 0` — считаются так же, как в таблице: 0 из 1.
- Из таблицы перенесены только задачи. Привычки ведутся с 5 октября 2026 — по точным отметкам.

## Ввод с телефона
Один раз на устройстве: лист «Отметить» → вставить fine-grained токен
(Only select repositories → этот репозиторий, Contents: Read and write). Хранится в `localStorage`.
Запись идёт с проверкой `sha`: если файл успели поменять с другого устройства — перечитать и повторить.

## Итоги недели — `data/reviews.json`

Разбор прошедшей недели пишет Claude **по просьбе Глеба в чате** (автоматического запуска нет).
Дашборд только показывает: карточка «Итоги недели» сверху, стрелками — прошлые недели.

Цифры берутся **только** из скрипта, чтобы совпадать с дашбордом:
```bash
python3 tools/week_stats.py            # прошедшая неделя пн–вс
python3 tools/week_stats.py 2026-10-12 # конкретная неделя (понедельник)
```

Одна запись = одна неделя, свежие добавляются в конец, повторный разбор той же недели заменяет прежний:
```json
{ "week": "2026-10-12", "to": "2026-10-18", "created": "2026-10-19",
  "habits": { "pct": 45.7, "done": 32, "of": 70, "prev": 50.0 },
  "tasks":  { "pct": 75.0, "done": 42, "of": 56, "prev": 55.6 },
  "title": "Одна строка — главный вывод недели",
  "sections": [
    { "t": "Задачи",         "p": "абзац" },
    { "t": "Где проседаешь", "li": ["пункт", "пункт"] },
    { "t": "На эту неделю",  "li": ["1–2 конкретных шага"] }
  ] }
```
`p` и `li` можно сочетать в одной секции. Текст — простой, без HTML и markdown.
